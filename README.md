# vibecom bar

See every Claude Code and Codex account, every usage window, and today's local
token activity from one native macOS menu bar app.

Part of [vibecom](https://vibecom.build). Your credentials stay in macOS
Keychain. Your prompts, responses, and transcript contents never leave your
Mac through vibecom bar.

![Animated overview of vibecom bar accounts and setup](docs/assets/overview.gif)

## What it does

- Shows Claude Code and Codex limits for every saved account.
- Marks the account each CLI will use and switches accounts with one click.
- Counts local Claude Code and Codex tokens without reading message content.
- Shows live token rate, hourly activity, seven-day totals, and API-equivalent cost.
- Warns before limits run out and when spent limits reset.
- Keeps credentials in Keychain and account metadata in a private local file.

## Install

The recommended production install will be Homebrew Cask:

```bash
brew install --cask dugbotek/tap/vibecom-bar
```

Until the first notarized release is published, build locally:

```bash
git clone https://github.com/DugboTek/vibecom-bar.git
cd vibecom-bar
./scripts/build-app.sh
open "Vibecom Bar.app"
```

Requires macOS 14 or newer plus the `claude` and/or `codex` CLI. See the
[getting-started guide](docs/getting-started.md) for account setup.

## Security at a glance

vibecom bar stores each saved account in an app-owned Keychain item. Claude
Code keeps ownership of its live `Claude Code-credentials` item; vibecom bar
never creates or relabels it. Periodic refreshes never read that live item.
This boundary prevents the repeating macOS password prompts that occur when
one app accidentally takes ownership of another app's credential.

Read the [security model](docs/security-model.md), [security policy](SECURITY.md),
and [troubleshooting guide](docs/troubleshooting.md) before reporting an auth
or Keychain problem.

## Provider compatibility

vibecom bar calls the same internal endpoints used by the provider CLIs:

| Purpose | Endpoint |
|---|---|
| Claude usage | `GET api.anthropic.com/api/oauth/usage` |
| Claude renewal | `POST console.anthropic.com/v1/oauth/token` |
| Claude identity | `GET api.anthropic.com/api/oauth/profile` |
| Codex usage | `GET chatgpt.com/backend-api/wham/usage` |
| Codex renewal | `POST auth.openai.com/oauth/token` |

These are undocumented APIs and may change without notice. The app keeps the
last good reading when a provider is temporarily unavailable.
