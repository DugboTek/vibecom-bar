# Support

Vibecom Bar is maintained in public. Choose the channel that matches the
problem so account details do not end up in the wrong place.

## Something is broken

Search [existing issues](https://github.com/DugboTek/vibecom-bar/issues), then
open a bug report with the macOS version, app version, provider, and exact
steps that reproduce the problem.

Do not paste tokens, passwords, full Keychain exports, `auth.json`, or the
contents of `Claude Code-credentials` into an issue.

## Repeated password prompts or login trouble

Start with the [troubleshooting guide](docs/troubleshooting.md). If it does not
resolve the problem, report the behavior without attaching credential data.

## Security or credential exposure

Use the private reporting path in [SECURITY.md](SECURITY.md). Do not open a
public issue for a vulnerability or suspected leaked secret.

## Product idea

Open a [feature request](https://github.com/DugboTek/vibecom-bar/issues/new?template=feature.yml)
and describe the workflow that is difficult today.
